# حزمة تطبيق Kitchen 3D Studio (ملف APK جاهز للتثبيت المباشر)

تم إعادة بناء وتوقيع أحدث نسخة كاملة من تطبيق **Kitchen 3D Studio (3D/2D Kitchen CAD, Cloud Sync & Cost Engine)** بنجاح (`BUILD SUCCESSFUL`).

---

## 📥 طرق ومسارات تنزيل حزمة الـ APK مباشرة

يمكنك تنزيل ملف الـ **APK** وتثبيته على هاتفك أو جهازك اللوحي عبر الطرق التالية:

1. **التحميل المباشر عبر قائمة الإعدادات في AI Studio (الطريقة الرسمية الأسرع):**
   - اضغط على أيقونة **الإعدادات / التصدير (Settings / Export)** في الشريط العلوي لواجهة Google AI Studio، ثم اختر **Generate / Download APK** لتنزيل الحزمة مباشرة إلى جهازك.
2. **التحميل المباشر من مستكشف ملفات المشروع (File Explorer):**
   - توجد الحزمة المترجمة مباشرة في مسار البناء الرسمي للمشروع:
     - [`/app/build/outputs/apk/debug/app-debug.apk`](/app/build/outputs/apk/debug/app-debug.apk)
   - افتح قائمة الملفات الجانبية (**Code / File Explorer**)، انتقل إلى المسار `app/build/outputs/apk/debug/app-debug.apk`، واضغط بزر الفأرة الأيمن (أو ضغطة مطولة على الهاتف) واختر **Download**.
3. **البناء السحابي التلقائي عبر GitHub Actions:**
   - يتضمن المشروع ملف سير العمل الجاهز [`.github/workflows/android-build.yml`](/.github/workflows/android-build.yml) الذي يستخرج حزمة `app-debug-apk` تلقائياً في تبويب **Actions -> Artifacts** عند التصدير إلى GitHub.

## ✨ أبرز الميزات المضمّنة في هذا الإصدار

1. **مزامنة سحابية عبر Firebase Firestore وتسجيل الدخول بحساب Google (`CredentialManager`):**
   - حفظ واسترجاع وتعديل تصاميم المطابخ سحابياً تحت حساب المستخدم الخاص به (`/users/{userId}/kitchen_designs/{designId}`) مع قواعد حماية صارمة (`firestore.rules`).
   - نموذج بيانات متكامل لمكونات المطبخ (`FirestoreKitchenComponent`) يحفظ الأبعاد (`widthCm`, `heightCm`, `depthCm`)، الإحداثيات (`posXCm`, `posYCm`)، المواد، الإكسسوارات الداخلية، والسعر الفردي لكل وحدة.
2. **حساب التكلفة الإجمالية تلقائياً والرسوم البيانية لتوزيع التكاليف:**
   - شارة سعر إجمالي مباشر (`$...`) في الشريط العلوي تتحدث لحظياً عند إضافة أو تعديل أي خزانة أو درج أو جهاز.
   - لوحة رسوم بيانية تفاعلية (**Donut Chart + Horizontal Bar Chart**) داخل نافذة تقرير المواد (`BOM`) تعرض توزيع التكاليف بدقة بين **المواد (Materials)**، **العمالة والتصنيع (Labor)**، و**الإكسسوارات والمفصلات (Accessories)**.
3. **خامات واقعية مولّدة بالذكاء الاصطناعي (Photorealistic Catalog Swatches):**
   - معاينة فورية لخامات عالية الدقة تشمل **رخام كرارا الإيطالي (`Carrara White Marble`)**، **خشب البلوط الطبيعي (`Natural Oak Wood`)**، و**جرانيت جالاكسي الأسود (`Black Galaxy Granite`)** كخلفيات اختيار في الكتالوج ومحدد الخامات.
4. **شبكة التخطيط 2D/3D، السحب والإفلات، ومؤشر التصادم الأحمر الفوري:**
   - تصنيف متكامل للوحدات (**خزائن سفلية، علوية، أدراج، زوايا، أبراج، أجهزة**) مع فحص توفر المساحة قبل الإفلات.
   - رسم **مربع تحذيري أحمر متقطع** في الوقت الفعلي حول أي خزائن تتقاطع أو تنتهك قواعد المسافة الهندسية لفتح الأبواب والأدراج.
5. **تخصيص الأبعاد القياسية للمواد وتصدير عروض الأسعار PDF والمشاركة الفورية:**
   - التحكم في الأبعاد الافتراضية لألواح الميلامين وقضبان الألمنيوم وسماكة شفرة القص (`Kerf`).
   - تصدير تقرير وعرض سعر PDF شامل ومشاركته مباشرة مع الورش أو العملاء عبر تطبيقات التواصل الاجتماعي أو البريد الإلكتروني.
